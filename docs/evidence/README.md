# Evidence index

This directory preserves development and qualification records, including failed
attempts. It is an archive, not a collection of instructions to run. Many reports
contain historical local filesystem paths; those paths are observations from the
author's test machine, not installation requirements.

The completed campaign did not authorize candidate promotion. Later software fixes
and passing infrastructure tests do not change earlier grades. Follow the links
within each summary for the underlying runs, reviews, hashes, and screenshots.

Raw JSON, test logs, patches, and screenshots are retained for traceability and
marked as generated research artifacts in `.gitattributes`. They are not compiled
into the app. Some records refer to ignored local runtimes, app bundles, container
images, or temporary workspaces that are not distributed with the source.
