## Required work before claiming this phase fully delivered

1. Finish or explicitly terminate the existing evaluation under its frozen policy, retain every failed/incomplete/integrity result, independently review it, and export the final outcome. Baseline retention is a valid result. Do not reclassify old partial costs as complete or relaunch to erase failures.
2. Record the actual app activation/rollback chain proof in an isolated synthetic fixture, including workspace+agent isolation, previous revision restoration, idempotence and stale-newer-binding rejection. This needs no model inference or production promotion.
3. Qualify actual Docker control-connectivity loss with an owned disposable guest, discarded unpublished output, blocked admission and successful reconciliation. A real Docker Desktop shutdown is unnecessary: same-package host opt-in tests can point the executor's private `host` at an app-owned Unix proxy, then drop its listener **and existing connections** and restore the same address. Public configuration currently pins the user's local Docker socket; ambient `DOCKER_HOST` is ignored. A real-CLI shim is simpler but only simulates control errors, so it is weaker evidence than the proxy.
4. After campaign completion, independently finish review of the source-only follow-ups, build them as a separate identity, run appropriate combined regressions, verify the native populated Harness/cost/error views and local package signature, and reconcile final documentation. Do not credit the old frozen binary with those corrections.

Source-only follow-ups already tracked: [native/upstream statuses](harness-combined-status-followup-manifest.json), [token completeness and rejected-review correction, version 2](phase2-metric-accounting-followup-manifest.v2.json), [bounded saved command metadata](phase2-harness-observation-metadata/manifest.json), root-owned audit-event filtering/cost UI, and instruction/read-only wire tests. The accounting correction blocks unknown/partial promotion but still allows an honest rejected review of unchanged evidence. None reconstructs missing historical measurements or observations.

The [independent source review](phase2-accounting-independent-source-review.json) now reports no blocking defect in the accounting, bounded-observation and presentation corrections: 24 source hashes matched; 21 deterministic backend tests / 51 including subtests and 9 frontend tests passed. This closes that source-review step, not the pending correction build/native qualification. “Complete” means terminal provider-receipt coverage, not independently measured physical compute or proven provider-counter accuracy.
